# GDS 与公开 Tutti v0.1.1 对照

两套后端使用同一物理 SSD、同一 16 GiB 数据文件、同一 trace 和同一组 12 个配置。GDS 取已成功完成的 A1/A2 样本，公开 Tutti 取 v0.1.1 的完整矩阵。设备、输入哈希和逐行校验见 `verification.json`。
